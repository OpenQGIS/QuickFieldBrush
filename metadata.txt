about=
  QuickFieldBrush 用于在 QGIS 中给矢量要素快速填写或批量修改属性。
  包含三个功能模块：
  1. 交互赋值：框选要素后右键选择属性值进行赋值，按图层记忆目标字段，支持频次与字母排序。
  2. 属性格式刷：支持从要素吸取值或手动选值，在地图上连续点击要素写入，支持停靠与悬浮。
  3. 历史面板：记录修改历史，支持地图单击居中高亮、双击选中要素、单步还原与导出 CSV。
  /
  QuickFieldBrush helps edit and assign vector attributes in QGIS.
  Modules:
  1. Interactive assignment: Box-select features and right-click to assign values. Remembers the target field per layer, with frequency and alphabetical sorting.
  2. Format painter: Pick an attribute value or absorb it from an existing feature, then click features on the canvas to write values continuously. Supports docked and floating modes with High-DPI hit testing.
  3. History panel: Logs edits, centers the canvas on selected records, reverts individual changes, and exports records to CSV.
