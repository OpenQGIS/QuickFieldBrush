# QuickFieldBrush (QGIS 极速属性赋级与格式刷插件)

**QuickFieldBrush** 是专为 QGIS 打造的极致轻量、高生产力矢量属性赋级与格式刷插件。

专注于解决 GIS 数字化、路网分级、水系拓扑等级划分、POI 分类等高频作业中“点开属性表改值慢、右键菜单繁琐、连续刷属性步骤多”的痛点。

---

## 核心功能

### 1. 交互赋级工具（框选 + 右键）
- **显式字段引导**：每次激活工具时主动弹出字段选择框，支持回车直接复用上次字段，按图层独立记忆，绝不误改主键 `fid`。
- **6 维智能排序条**：
  - `A-Z` / `Z-A`：首字母正序 / 倒序；
  - `多↓` / `少↑`：**出现频次降序 / 升序**，高频分类（如 `service`、`footway`、`residential`）自动置顶，一眼即赋；
  - `1-9` / `9-1`：数值等级自然排序（1, 2, 3... 10 正确排序）；
- **要素频次透视**：候选值后直接标明该值在当前图层中已存在的要素总数（如 `service (1,689)`）。
- **右键顶部一键换字段**：右键菜单直接提供 `[⚙️ 切换赋级字段...]`，切换后 40ms 无缝重新呼出菜单。

### 2. 属性格式刷工具（常驻置顶控制台）
- **无模态置顶控制台**：悬浮在 QGIS 顶层，边在地图上点击要素刷入，边在面板上随时切换字段与属性值，毫秒级生效。
- **一键吸取属性**：选中某个参照要素，点击“吸取属性”即可捕获其属性值并直接上刷。
- **瞬时绿色闪烁反馈**：刷入成功后目标要素闪烁 180ms 绿色高亮，作业直观安心。
- **支持 ESC 退出**：随时按 ESC 退出格式刷模式。

### 3. 历史记录面板（类似 Adobe Illustrator 浮动历史面板）
- **独立工具栏入口**：点击工具栏时钟图标 🕒 即可随时展开或收起历史记录浮动面板。
- **全流程修改记录**：自动记录格式刷单点写入与框选批量赋级的每一次修改，完整保存修改前原值 (`old_val`) 与新值 (`new_val`)。
- **地图画布实时联动**：
  - **单击记录**：地图瞬间居中平移至该要素，并触发 350ms 翠绿高亮闪烁，改了哪里一目了然；
  - **双击记录**：自动设为当前图层并选中对应要素；
- **单步精准还原 (Revert)**：点击记录卡片右侧的 `↺` 按钮，一键精准将要素回滚到修改前的值。
- **撤销最近一步 (Undo Latest)**：快速回滚最新一次尚未撤销的修改。
- **导出 CSV 审计台账**：一键将全流程操作历史导出为标准 CSV 表格（含 UTF-8 BOM，Excel 直接双击不乱码）。
- **面板置顶支持**：支持图钉一键置顶悬浮在 QGIS 最上层，操作无拘束。

## 安装方法

1. 将 `QuickFieldBrush` 文件夹复制到 QGIS 插件目录：
   - Windows: `C:\Users\<用户名>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\`
2. 打开 QGIS，进入菜单栏 `插件` -> `管理并安装插件` -> `已安装`，勾选 `QuickFieldBrush` 即可。
